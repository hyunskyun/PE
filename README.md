# 50m 달리기 자세 분석 프로그램 (연구용 프로토타입)

측면에서 촬영한 50m 단거리 달리기 영상을 입력받아, MediaPipe Pose로
관절 좌표를 추출하고 조건문(if-else) 기반 임계값 비교로 자세 오류를
자동 판정하는 분석 엔진입니다.

> **중요**: 이 프로그램은 탐구 보고서를 위한 **연구용 프로토타입**이며,
> **실제 달리기 영상으로 인식 성능을 검증하지 않았습니다.** 여기서 쓰는
> 임계값은 조정 가능한 예시 기준이지 과학적으로 확정된 값이 아닙니다.

## 처리 순서

```
영상 입력 -> 프레임 단위 분할 -> MediaPipe Pose 랜드마크 추출
   -> 좌표 기반 각도·거리 계산 -> 구간 분류(가속/최대 속도)
   -> 착지 검출 -> 조건문 비교 -> 오류 판정 -> 교정 피드백 출력
```

## 폴더 구조

```
posture_analysis/
  constants.py      랜드마크 번호, 진행 방향, 다리길이 근사 비율 등 공통 상수
  geometry.py        각도/거리 계산 (진행 방향 기준 부호 있는 상체 기울기 포함)
  metrics.py          프레임 지표 계산 + 평균 속도/프루드 수 등 기록 지표
  phase.py             분석 구간 경계 결정, 가속/최대 속도 구간 분류
  thresholds.py        구간별 권장 범위 + 오류별 교정 문장 (조정 가능한 예시 값)
  judge.py              조건문 기반 판정 로직 (음수 기울기 = 후경 별도 판정)
  landing.py            착지 후보 검출 (평활화·최소 돌출량·근접 후보 병합)
  pose_extractor.py      OpenCV + MediaPipe 의존부 (여기만 무거운 의존성)
  analyzer.py             전체 파이프라인 (extractor 주입으로 mock 테스트 가능)
  report.py                이탈 프레임 비율/검출률/점수 집계 및 텍스트 출력
main.py                     CLI 실행 진입점
tests/                       순수 로직 단위 테스트 + mock 파이프라인 테스트
.github/workflows/test.yml   CI (순수 로직 테스트만 실행)
```

## 실행 방법

```bash
pip install -r requirements.txt
python main.py --video sprint.mp4 --direction right
```

전체 옵션 예시:

```bash
python main.py \
  --video sprint.mp4 \
  --direction right \
  --record-time 7.4 \
  --leg-length 0.92 \
  --analysis-start 0.5 \
  --acceleration-end 2.6 \
  --analysis-end 8.0 \
  --output result.json
```

| 옵션 | 설명 |
|---|---|
| `--direction right\|left` | 화면 기준 진행 방향. 생략 시 엉덩이 이동으로 자동 추정 (추정 실패 시 직접 입력 필요) |
| `--record-time` | 50m 기록(초). 입력하면 평균 속도와 프루드 수를 계산 |
| `--leg-length` | 다리 길이(m). 프루드 수 계산용. 직접 실측값 입력 권장 |
| `--height` | 신장(cm). 참고 정보. 다리 길이 미입력 시 근사에만 제한적으로 사용 |
| `--analysis-start` / `--analysis-end` | 분석 시작/종료 시각(초) |
| `--acceleration-end` | 가속 구간 종료 시각(초). **생략 시 분석 구간의 40% 지점을 자동 추정값으로 사용하는데, 이 40%는 근거가 약한 추정치일 뿐이므로 실제 통과 시각을 직접 입력하는 것이 좋습니다** |
| `--output` | 프레임별 상세 결과 + 요약 JSON 저장 경로 |

촬영 방향(`--direction`)과 구간 시각을 사용자가 올바르게 입력해야 분석이
의미를 가집니다. 잘못 입력하면 전방/후방 기울기와 착지 위치의 부호가
반대로 해석됩니다.

## 출력 예시

```
[가속 구간]
  상체 기울기: 평균 11.20 (권장 범위 15~45) -> 판정: 권장 범위 이탈
    유효 측정 프레임: 120 / 기준 이탈 프레임: 24 (이탈 비율 20.0%)
  무릎 굴곡각(착지 시): 평균 152.30 (권장 범위 100~145) -> 판정: 권장 범위 이탈
    검출된 착지 수: 8 / 오류 착지 수: 2 (오류 착지 비율 25.0%)
  ...
  구간 자세 점수: 62.5 / 100

[검출 품질]
  전체 분석 프레임 수: 240
  사람 검출 성공 프레임 수: 220
  유효 관절 측정 프레임 수: 210
  MediaPipe 유효 검출률: 87.5%

[달리기 기록 지표]
  50m 기록: 7.40초
  50m 평균 속도: 6.76 m/s
  다리 길이: 0.92 m (직접 입력)
  프루드 수: 5.06 (50m 전체 평균속도 기준, 신체 크기를 고려한 무차원 속도 비교용)
```

검출률이 낮으면(기본 60% 미만) 점수 신뢰도 경고가 함께 출력됩니다.

## 지표 정의에서 주의할 점

- **양 발목 수평 간격 비율(ankle_separation_ratio)은 실제 보폭(stride
  length)이 아닙니다.** 한 프레임에서 양 발목이 벌어진 수평 거리를 화면상
  신체 길이로 나눈 간접 지표입니다. 실제 보폭은 같은 발의 연속 착지 위치
  차이와 픽셀-미터 보정이 필요하며, 아직 구현하지 않았습니다
  (`metrics.py`의 TODO 참고).
- **상체 기울기는 부호 있는 값**입니다. 진행 방향 기준 전방 기울기가
  양수, 후방 기울기(후경)가 음수이며, 음수는 별도의 후경 오류로 판정합니다.
- **무릎 각도는 착지 후보 프레임에서만 판정**합니다. 회복기(swing)에는
  무릎이 크게 굽는 것이 정상이라, 착지가 아닌 프레임의 무릎 각도는 분석용
  원자료로만 기록합니다.

## 프루드 수(Froude number)

```
Fr = v² / (g × L)      v: 속도(m/s), g: 9.81 m/s², L: 다리 길이(m)
```

- 신체 크기를 고려해 속도를 무차원화한 지표로, **신장이 다른 학생 간
  속도 비교**나 자세 지표와 성능의 관계 분석에 씁니다.
- 여기서 계산하는 값은 **50m 전체 평균속도 기준**입니다. 구간별(가속/최대
  속도) 프루드 수는 구간별 거리와 통과 시간이 있어야 하므로 만들지 않습니다.
- **프루드 수만으로 자세의 우수성을 판정하지 않습니다.**
- 다리 길이를 입력하지 않으면 신장 × 0.53(`LEG_LENGTH_HEIGHT_RATIO`)으로
  근사하며, 결과에 근사값임이 표시됩니다. 이 비율은 대략적인 근사이지
  정확한 생체 측정값이 아니므로 실측 입력을 권장합니다.

## 테스트

```bash
python -m unittest discover -s tests -t . -v
```

테스트는 표준 라이브러리만 사용하며 mediapipe/opencv 없이 실행됩니다.
전체 파이프라인은 합성 랜드마크와 가짜 추출기(mock)로 검증합니다.

**개발 환경과 실행 환경의 차이**: CI(`.github/workflows/test.yml`)와
단위 테스트는 `requirements-test.txt`(추가 의존성 없음)만 사용합니다.
실제 영상을 분석하려면 `requirements.txt`의 opencv-python과 mediapipe를
설치해야 하며, 이 부분(`pose_extractor.py`)은 CI에서 검증되지 않습니다.

## 임계값(판정 기준) 조정하기

`posture_analysis/thresholds.py`의 `THRESHOLDS` dict 숫자만 바꾸면
판정 기준이 즉시 바뀝니다. 현재 값은 일반적인 스프린트 생체역학 자료를
참고한 **예시 기준**이므로, 문헌 수치·코치 자문·실측 데이터로 보정해서
사용해야 합니다.

## 한계

- **실제 영상 검증 미완료**: MediaPipe 인식 정확도, 착지 검출 파라미터
  (평활화 윈도, 최소 돌출량, 최소 착지 간격)는 실제 달리기 영상으로
  검증·보정하지 않았습니다.
- **2D 측면 영상의 한계**: 깊이 정보가 없어 3D 각도나 좌우 비대칭을
  정확히 구하지 못하고, 카메라와 평행하지 않은 촬영은 오차를 키웁니다.
- **지면반발력 미측정**: 착지는 발목 y좌표 파형으로 근사할 뿐 실제 지면
  접촉을 측정하지 않습니다.
- **픽셀-미터 변환 없음**: 화면상 신체 길이(코-발목 px 거리)를 스케일
  기준으로 쓰는 근사이며, 신장을 입력해도 픽셀-미터 변환이 이루어지는
  것은 아닙니다.
- **낮은 검출률에서는 점수 신뢰도가 낮습니다**: 점수는 측정에 성공한
  프레임만으로 계산되므로 반드시 검출률과 함께 해석해야 합니다.
- **가속 구간 경계의 40% 자동 추정은 근거가 약한 fallback**입니다.
  실제 통과 시각 입력을 권장합니다.

## 다른 형태로 확장하기

핵심 로직(`posture_analysis/`)은 UI와 분리된 순수 함수 위주라서 정적
웹 프론트엔드(JSON 결과 시각화), 안드로이드 앱(MediaPipe Tasks API로
로직 이식), 데스크톱 프로그램(PyInstaller 패키징) 등으로 감쌀 수
있습니다. 어떤 형태든 판정 로직(`judge.py`, `thresholds.py`)은 그대로
재사용할 수 있습니다.
